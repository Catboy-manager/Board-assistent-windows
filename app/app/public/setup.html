📋 Kanban Board — включение голоса со второго ПК / телефона

Браузер блокирует микрофон на сайтах, которым не доверяет (без безопасного соединения). Для голосовых команд нужно один раз установить наш корневой сертификат. Здесь можно проверить, принят ли он.

Проверка соединения…

Как проверилось (что означают цвета)

● Зелёный — сертификат установлен правильно. Нажмите кнопку «Войти» (появится выше), откройте сайт по защищённому адресу и разрешите микрофон: голосовой ввод заработает.
● Красный — браузер всё ещё не доверяет сертификату. Причины и исправление ниже.

Скачать сертификат заново

⬇️ Скачать сертификат kanban-ca.pem

Это тот же файл и по адресу: http://192.168.1.100:8080/ca.pem

Установка (важно: после установки полностью перезапустите браузер)

Windows (Chrome / Edge)

1. Скачайте ca.pem и переименуйте в kanban-ca.crt (двойной клик по .pem часто просто открывает блокнот — обязательно смените расширение).
2. Правый клик по файлу → Установить сертификат → «Текущий пользователь» → далее.
3. Выберите «Поместить все сертификаты в хранилище» → Обзор → Доверенные корневые центры сертификации → ОК → Далее → Готово.
4. Важно: закройте Chrome/Edge полностью (все окна, через «Выход») и откройте заново.

macOS (Safari / Chrome)

1. Дважды кликните ca.pem — откроется «Связка ключей».
2. Дважды кликните сертификат → раскройте «Доверие» → «Всегда доверять» → закройте окно (введите пароль).
3. Перезапустите браузер полностью.

Android (Chrome)

1. Скачайте ca.pem (кнопка выше).
2. Настройки → Безопасность → Шифрование и учётные данные → Установить сертификат → Сертификат ЦС → выберите файл.
3. Android 14+ может показать чёрный экран — перейдите в «Настройки» → «Сертификаты пользователя» и установите оттуда.
4. Перезапустите Chrome (закройте из списка приложений).

iPhone / iPad (Safari)

1. Откройте http://192.168.1.100:8080/ca.pem → скачайте.
2. Настройки → Профиль загружен → Установить; затем Настройки → Основные → Об этом устройстве → Настройки доверия сертификатам → включите доверие.
3. Перезапустите Safari.

Linux (свой ПК)

sudo cp ca.pem /usr/local/share/ca-certificates/kanban-board.crt
sudo update-ca-certificates
Перезапустите браузер.

Если используется Firefox

Firefox не использует системное хранилище: проще всего пользоваться Chrome / Edge / Chromium. Либо в Firefox: Настройки → Приватность и защита → Сертификаты → «Просмотр» → вкладка «Центры сертификации» → «Импортировать» → выбрать ca.pem → отметить «Доверять при изучении сайтов» → ОК → перезапуск Firefox.
Если после всех шагов проверка выше всё ещё красная — сообщите, какая ОС и браузер на втором ПК, и что именно показывает проверка (или скопируйте отсюда ссылку вида https://IP:8443).
