# Kanban Board — Desktop (Windows)

Полноценное приложение: канбан-доска + ИИ-ассистент (opencode) + голосовой ввод (локальное распознавание faster-whisper) в собственном окне, с системным треем и автозапуском. Сервер встроен; по умолчанию слушает `127.0.0.1` (LAN-доступ настраивается в `config.json` → `host`).

## Быстрый старт

Нужен **Node.js LTS** (проверено на 22).

```bash
cd kanban-desktop\windows
npm install
npm start
```

## Дистрибутивы

```bash
cd kanban-desktop\windows
npm run dist
```

Появятся в `windows\dist`:
- `Kanban Board Setup ...exe` — установщик (меню «Пуск», ярлык рабочего стола);
- `Kanban Board ...exe` — portable-версия (без установки).

Если сборка идёт на Windows — всё готово к работе. Сборка возможна и с Linux (нужен Wine), но проще собирать на Windows. Сборка **не включает** `config.json` и `data/` — приложение создаёт их в `%USERPROFILE%\.kanban-desktop` при первом запуске (из папки приложения переносятся только данные, если там уже что-то было).

## Где что лежит

| Что | Путь |
|---|---|
| Данные доски (db.json, config.json, uploads, zвуки) | `%USERPROFILE%\.kanban-desktop` |
| Проекты, которые ИИ создаёт/изменяет | `%USERPROFILE%\AI Projects` |
| Модель распознавания речи (75 МБ) | внутри папки приложения `app\stt` |

## Зависимости для полной функциональности

- **ИИ-ассистент**: бинарь `opencode.exe`. Установка: `curl -fsSL https://opencode.ai/install | bash` (кладёт в `%USERPROFILE%\.opencode\bin`). Путь находится автоматически; при необходимости укажите свой в `%USERPROFILE%\.kanban-desktop\config.json` → `ai.opencodeBin`.
- **Распознавание речи**: нужен `python` (Python 3) в PATH + `pip install faster-whisper pyav`. Без него голос запишется и уйдёт ИИ без распознанного текста.
- **Озвучка (TTS)**: `python` + `pip install piper-tts`, модель piper в `%USERPROFILE%\.kanban-desktop\tts\` (`ru_RU-irina-medium.onnx` + `.json`), либо espeak-ng, либо отключите 🔊.

## Работа с приложением

- Трей — иконка: открыть/скрыть окно, открыть в браузере, автозапуск, перезапуск сервера, выход.
- Закрытие окна крестиком убирает в трей.
- Глобальная клавиша `Ctrl+Shift+K` — показать/скрыть.
- Внутри всё как в веб-версии: доска, ИИ-панель, голос 🎙️ (нажмите — говорите — пауза отправит), вкладка 📁 — файлы проектов, вкладка 🔔 — уведомления.
- **Голосовая активация (wake-слово) отключена** — голосовой ввод в чате работает, но постоянное прослушивание не подключается.

> На Windows браузерное распознавание речи (Google) обычно недоступно — приложение использует локальный серверный STT, это работает всегда.

## Пересылка уведомлений со смартфона

Если включить LAN-доступ (`host: "0.0.0.0"` в `config.json`), с телефона в той же сети можно слать уведомления на доску:

- на телефоне откройте `http://<IP-ПК>:8080/notify.html`, либо
- настройте автоматизацию (HTTP Shortcuts / MacroDroid / Tasker) слать POST на `http://<IP-ПК>:8080/api/notify/send` с JSON `{ "title": "...", "text": "...", "app": "...", "chat": "..." }`.

## Безопасность

- `config.json` (в `%USERPROFILE%\.kanban-desktop`) содержит секреты (токен Telegram, ключ консоли, ключ ИИ) — **не копируйте и не передавайте** эту папку третьим лицам и не коммитьте.
- Сборка не включает эти файлы в дистрибутив.
- Основные API без авторизации — это персональный инструмент для локальной сети; не выходите в интернет без reverse-proxy с аутентификацией.
- Опциональные ключи: `KANBAN_NOTIFY_KEY`, `KANBAN_SMART_KEY`, `KANBAN_CONSOLE_KEY`.
